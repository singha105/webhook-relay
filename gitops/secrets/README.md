# Sealed secrets

Committed `SealedSecret` resources go here. ArgoCD applies them; the
Sealed Secrets controller decrypts them in-cluster into ordinary `Secret`s.

This directory is intentionally empty of secrets right now — see
[docs/secrets.md](../../docs/secrets.md) for why. Everything this system needs
is either generated by Terraform at provision time (the Postgres and Grafana
passwords, which is strictly better than encrypting and committing) or
generated per-endpoint at runtime and stored in Postgres as application data.

Seal a new one with:

```bash
kubectl create secret generic my-secret -n webhook-relay \
  --from-literal=key=value --dry-run=client -o yaml \
| kubeseal --controller-name sealed-secrets-controller \
           --controller-namespace kube-system --format yaml \
> gitops/secrets/my-secret-sealed.yaml
```
